# Options Master Lab

An IBKR Desktop-first course for learning business research, valuation, charts and options. Open `index.html` directly or serve the directory with `python3 -m http.server 8765` and visit http://localhost:8765.

The site uses local static files and a pinned D3 distribution. It has no build step, account, data feed or broker integration. Progress stays in this browser. Export a backup from the sidebar before changing devices. Private notes are not sent anywhere.

See PRD.md for requirements and PLAN.md for execution gates. Source notes live in sources/; review evidence in reviews/. The original release remains available in Git at c0f5631. Publication is separate from local delivery.
